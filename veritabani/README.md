
# METAKS Depo Veritabanı

## Klasörler

- `data/raw`: Orijinal kaynak veriler

- `data/interim`: Ara işlem dosyaları

- `data/processed`: Nihai ürün dosyaları

- `data/reference`: Manuel eşleme ve yardımcı veriler

- `images/working`: İşlem gören görseller

- `images/final`: Nihai ürün görselleri

- `reports/excel`: Kontrol ve dönüşüm raporları

- `scripts`: Veri işleme scriptleri

- `sql`: PostgreSQL şeması

- `archive`: Eski ve kullanılmayan dosyalar
